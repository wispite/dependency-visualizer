## Этап 2. Сбор данных

### Цель этапа

Реализация механизма получения информации о прямых зависимостях NuGet-пакета заданной пользователем версии с использованием URL-адреса репозитория.

### Реализованные возможности

На данном этапе реализованы:

- Получение информации о репозитории NuGet через Service Index.
- Определение адреса ресурса PackageBaseAddress.
- Получение манифеста пакета в формате `.nuspec`.
- Извлечение прямых зависимостей указанной версии пакета.
- Получение названий зависимостей, требуемых версий и целевых платформ.
- Вывод списка прямых зависимостей в консоль.
- Обработка ошибок при получении и разборе данных.

### Принцип работы

Для получения информации используется API NuGet V3.

Сначала приложение обращается к Service Index репозитория и определяет адрес ресурса PackageBaseAddress. Затем по имени и версии пакета формируется URL для загрузки файла `.nuspec`.

Полученный XML-файл обрабатывается средствами стандартной библиотеки Python. Из него извлекаются сведения о прямых зависимостях пакета, включая версии и целевые платформы.

### Используемые технологии

- **Язык программирования:** Python 3.
- **API:** NuGet V3.
- **Форматы данных:** JSON и XML.
- **Используемые библиотеки:** `urllib`, `json`, `xml.etree.ElementTree`.
- **Интерфейс:** CLI.

Для получения информации о зависимостях не используются менеджеры пакетов и сторонние библиотеки.

```bash
python3 src/main.py --package Newtonsoft.Json --repository https://api.nuget.org/v3/index.json --mode remote --version 13.0.3
```

### Результат выполнения

При успешном выполнении программа выводит список прямых зависимостей указанного пакета. Для каждой зависимости отображаются:

- Название пакета.
- Требуемая версия.
- Целевая платформа (Target Framework).


### Тестирование

**1. Получение информации о реальном пакете Newtonsoft.Json:**

```bash
python3 src/main.py --package Newtonsoft.Json --repository https://api.nuget.org/v3/index.json --mode remote --version 13.0.3
```

Ожидаемый результат: программа обращается к NuGet, получает сведения о пакете и его зависимостях.

**2. Проверка другого пакета:**

```bash
python3 src/main.py --package Serilog --repository https://api.nuget.org/v3/index.json --mode remote --version 4.2.0
```

Ожидаемый результат: программа получает данные другого существующего пакета.

**3. Проверка несуществующего пакета:**

```bash
python3 src/main.py --package NonExistingPackage123456 --repository https://api.nuget.org/v3/index.json --mode remote --version 1.0.0
```

Ожидаемый результат: программа сообщает об ошибке получения данных пакета.

**4. Проверка некорректного URL репозитория:**

```bash
python3 src/main.py --package Newtonsoft.Json --repository invalid-url --mode remote --version 13.0.3
```

Ожидаемый результат: программа отклоняет некорректный URL.
