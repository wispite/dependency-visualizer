## Этап 5. Визуализация графа зависимостей

### Цель

Реализовать графическое представление построенного графа зависимостей с использованием языка описания графов Graphviz DOT.

### Реализованные возможности

- Формирование текстового описания графа на языке Graphviz DOT.
- Отображение вершин и направленных рёбер.
- Выделение циклических зависимостей.
- Сохранение DOT-описания в файл.
- Генерация SVG-изображения с помощью Graphviz.
- Автоматическое открытие готовой визуализации в браузере в удалённом режиме.

За генерацию DOT-описания и SVG-изображения отвечает модуль `src/visualizer.py`.

### Используемые средства

- Graphviz — преобразование DOT-описания в графическое изображение.
- SVG — формат сохранения визуализации.
- Python `subprocess` — запуск Graphviz из программы.
- Python `webbrowser` — автоматическое открытие изображения в браузере.

### Подготовка окружения

Проверка установленного Graphviz:

```bash
dot -V
```

Если Graphviz установлен, команда выводит информацию о его версии.

### Тестирование

**1. Визуализация реального NuGet-пакета Newtonsoft.Json версии 13.0.3:**

```bash
python3 src/main.py --package Newtonsoft.Json --repository https://api.nuget.org/v3/index.json --mode remote --version 13.0.3
```

В результате программа:

1. Получает данные пакета из NuGet.
2. Строит полный граф прямых и транзитивных зависимостей.
3. Формирует DOT-описание графа.
4. Сохраняет DOT-файл в каталоге `visualizations`.
5. Генерирует SVG-изображение.
6. Автоматически открывает SVG в браузере.

**2. Проверка созданных файлов:**

```bash
ls -lh visualizations/
```

После успешной генерации должны появиться:

```text
visualizations/
├── Newtonsoft.Json.dot
└── Newtonsoft.Json.svg
```

**3. Повторное открытие SVG-изображения:**

```bash
open visualizations/Newtonsoft.Json.svg
```

**4. Просмотр DOT-описания:**

```bash
open -a TextEdit visualizations/Newtonsoft.Json.dot
```

**5. Проверка визуализации тестового графа A:**

```bash
python3 src/main.py --package A --repository tests/repository.json --mode test --version 1.0
```

В тестовом режиме файлы DOT и SVG сохраняются, но автоматическое открытие браузера не выполняется.

### Сравнение со штатными инструментами .NET

Для сравнения результатов используется команда:

```bash
dotnet list package --include-transitive
```

Она позволяет получить список верхнеуровневых и транзитивных пакетов проекта.

Для воспроизведения сравнения на отдельном тестовом проекте можно выполнить:

```bash
mkdir -p /tmp/nuget-comparison
cd /tmp/nuget-comparison

dotnet new classlib --framework net10.0

sed -i '' 's/net10.0/netstandard1.3/' nuget-comparison.csproj

dotnet add package Newtonsoft.Json --version 13.0.3

dotnet list package --include-transitive
```

В данном эксперименте используется целевая платформа `.NET Standard 1.3`, чтобы сопоставить зависимости соответствующей группы пакета Newtonsoft.Json.

### Объяснение возможных расхождений

Результаты анализатора и `dotnet list package --include-transitive` могут различаться по следующим причинам:

1. Анализатор извлекает зависимости непосредственно из метаданных выбранного NuGet-пакета.
2. .NET CLI показывает разрешённые зависимости всего проекта, а не только зависимости одного выбранного пакета.
3. Результат восстановления зависимостей зависит от целевой платформы проекта.
4. Некоторые пакеты могут автоматически подключаться целевой платформой. Например, `NETStandard.Library` для `.NET Standard 1.3`.
5. Различия в версиях и правилах разрешения зависимостей могут влиять на итоговый состав списка.

В эксперименте с Newtonsoft.Json 13.0.3 все шесть зависимостей группы `.NET Standard 1.3` присутствовали в выводе .NET CLI. Однако команда `dotnet list package --include-transitive` не отображает полную структуру рёбер зависимостей выбранного пакета. Она формирует список пакетов проекта.

Таким образом, сравниваются состав найденных пакетов и результаты разрешения зависимостей, а не идентичность двух графов.

### Результат

Реализована визуализация графа зависимостей с использованием Graphviz. Программа автоматически формирует DOT-описание, создаёт SVG-изображение и открывает его в браузере.

Для проверки использован реальный NuGet-пакет Newtonsoft.Json версии 13.0.3. Также проведено сравнение полученных данных с результатами штатной команды .NET CLI `dotnet list package --include-transitive`.
