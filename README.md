## Этап 4. Дополнительные операции

### Цель этапа

Реализация механизма поиска обратных зависимостей пакетов. Обратными зависимостями являются пакеты, которые напрямую или транзитивно зависят от заданного пользователем пакета.

### Реализованные возможности

На данном этапе реализованы:

- Построение обратного графа зависимостей на основе исходного графа репозитория.
- Поиск прямых обратных зависимостей заданного пакета.
- Поиск транзитивных обратных зависимостей.
- Использование итеративного алгоритма обхода DFS без рекурсии, реализованного на предыдущем этапе.
- Обработка циклических зависимостей при поиске обратных зависимостей.
- Вывод найденных обратных зависимостей в консоль.
- Обработка случая, когда у пакета отсутствуют обратные зависимости.

### Тестирование

Поиск обратных зависимостей реализован для локального тестового режима.

**1. Проверка обратных зависимостей пакета D:**

```bash
python3 src/main.py --package D --repository tests/repository.json --mode test --version 1.0
```

Ожидаемые обратные зависимости:

```text
B
C
A
```

**2. Проверка обратных зависимостей пакета B:**

```bash
python3 src/main.py --package B --repository tests/repository.json --mode test --version 1.0
```

Ожидаемая обратная зависимость:

```text
A
```

**3. Проверка обратного графа с циклом:**

```bash
python3 src/main.py --package F --repository tests/repository.json --mode test --version 1.0
```

Проверяется обнаружение обратного цикла:

```text
F -> H -> G -> F
```

**4. Проверка пакета без обратных зависимостей:**

```bash
python3 src/main.py --package I --repository tests/repository.json --mode test --version 1.0
```

Ожидаемый результат: обратные зависимости отсутствуют.

### Ограничение

Поиск обратных зависимостей в удалённом режиме NuGet V3 не реализован, поскольку используемый механизм получения метаданных не предоставляет необходимого глобального поиска всех пакетов, зависящих от выбранного пакета.

Поэтому проверка обратных зависимостей выполняется в тестовом режиме.

### Результат

Реализован поиск прямых и транзитивных обратных зависимостей на основе обратного графа с использованием итеративного DFS. Предусмотрено обнаружение циклов и обработка пакетов без обратных зависимостей.
