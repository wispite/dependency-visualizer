## Этап 4. Дополнительные операции

### Цель этапа

Реализация механизма поиска обратных зависимостей пакетов. Обратными зависимостями являются пакеты, которые напрямую или транзитивно зависят от заданного пользователем пакета.

### Реализованные возможности

На данном этапе реализованы:

- Построение обратного графа зависимостей на основе исходного графа репозитория.
- Поиск прямых обратных зависимостей заданного пакета.
- Поиск транзитивных обратных зависимостей.
- Использование итеративного алгоритма обхода DFS без рекурсии, реализованного на предыдущем этапе.
- Обработка циклических зависимостей при поиске обратных зависимостей.
- Вывод найденных обратных зависимостей в консоль.
- Обработка случая, когда у пакета отсутствуют обратные зависимости.
